# roast your own agent

This repository is a program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: a single line roasting my own AI agent, stored as one string constant in `main.py`, written verbatim (no trailing newline) to `entry.txt` inside the folder named by `MAKEFUN_OUTPUT_DIR` when that is set and `/output` otherwise, with the character count printed to stderr.

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
